# QA

학교 망 맥북 `172.30.14`에서 확인한 기록. 새 시도는 아래에 날짜와 반을 붙여 추가한다.

기준선은 태그 `marker/airplay-player` (커밋 `8357942`).

## 주소 건네기 — 에어플레이 51010

칠판이 맥북의 음악 주소를 받아 플레이어를 연다.

| 반 | 주소 | 명령 | 파일 | 소리 | 화면 |
|---|---|---|---|---|---|
| 2-8반 | 172.30.7.209 | 받음 | 받음 | 남 | 플레이어로 바뀜 |
| 2-1반 | 172.30.5.24 | 약 0.08초에 받음 | 가져오지 못함 | 없음 | 로더만 돔 |
| 2-6반 | 172.30.8.20 | 연결 안 됨 | — | 없음 | — |
| 2-7반 | 172.30.7.104 | 연결 안 됨 | — | 없음 | — |

2-1반은 명령 길과 파일 길이 다르다. 명령은 되고, 칠판이 파일을 받으러 오는 길은 막혀 있다.

칠판은 안드로이드다. 같은 와이파이 이름에 20대가 있다. 주소가 확인된 것은 위 4대뿐이다.

|---|---|---|---|---|---|
| | | | | | |

## 20대 동시 재생 — 아직

한 곡을 20대에 같이 보낸 결과는 여기 적는다. 몇 대에서 소리가 났는지, 화면이 유지됐는지, 맥북이 중간에 끊겼는지.

## 스피커로 밀어 넣기

학생이 확인한 기대 동작: 맥북이 노래를 재생해 칠판 스피커로 넣으면 유튜브 화면은 유지되고 소리만 겹친다. 갤럭시는 재생 버튼만 누른 것으로 본다.

시험음이 안 들린 적은 있다. 포트가 틀린 것이 아니다. 에어플레이 스피커는 ALAC 꾸러미만 받는다. 안드로이드라서 ALAC인 것은 아니다.

| 항목 | 값 |
|---|---|
| 표본 | 1초에 44100번 |
| 채널 | 좌우 두 줄 |
| 묶음 | 352칸 |
| 형식 | ALAC |
| 포트 | 연결 답장에 적힌 번호. 연결마다 바뀜 |

### P1 시험 — 아직

대상: 2-8반만. 화면이 그대로인지, 소리가 나는지.

기록할 칸:

- 날짜
- 연결 답장에 포트가 있었는지
- 화면이 유지됐는지
- 소리가 났는지
- 안 났으면 무음인지, 연결이 끊겼는지
