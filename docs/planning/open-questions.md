# 아직 모름

P1 시험 전에 코드로 추측해 메우지 않는다. 시험 결과에 답을 적는다.

1. 박자 신호를 ALAC 꾸러미와 같이 보내야 하는가.
2. 잠근 꾸러미만 받는가. 잠그지 않은 ALAC도 소리가 나는가.
3. 2-1반 스피커에 맥북이 닿는가. 파일 가져오기가 막힌 것과 별개다.
4. 2-6반, 2-7반은 명령 연결이 망에서 막힌 것인가, 칠판이 꺼진 것인가.
5. 20대 전부가 맥북에서 스피커까지 닿는가. 같은 와이파이 이름이어도 방 망이 다를 수 있다.
6. 맥북 한 대가 ALAC 20줄을 곡 끝까지 버티는가. 대당 약 초당 1.4메가, 합쳐 약 28메가다.
