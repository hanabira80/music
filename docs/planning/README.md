# 학교 칠판 음악

화면에서 반을 고르고 재생한다. 폰은 버튼만 누른다. 학교 망 안의 맥북이 안드로이드 칠판에 연결한다. 같은 와이파이 이름의 칠판 20대에 한 번에 보낸다. 교실은 7칸×3층이다.

기준 커밋 `8357942`, 태그 `marker/airplay-player`. 이 태그는 칠판이 플레이어를 여는 방식까지다. 저장소는 비공개 `hanabira80/music`.

Vercel에 올리면 칠판 주소에 닿지 않는다. 앱은 학교 망 맥북에서 실행한다. 맥북은 `172.30.14`이다.
